# 墨藍藝廊｜SillyTavern Chat Interface v1.12.1

本版本識別碼：`1.12.1-statusbar-inner-scroll`。狀態欄上下外框固定完整顯示，只有中間內容區可滑動。

一套奶油白、墨黑與鈷藍配色的 SillyTavern 第三方前端擴充。它不取代或搬移聊天資料，只以全螢幕介面操作 SillyTavern 現有角色、群組、訊息、世界書與生成資訊。

## 安裝

1. 解壓縮 molan-gallery-st-extension.zip。
2. 將整個 molan-gallery-st-extension 資料夾放入：
   - 使用者安裝：SillyTavern/data/<你的使用者名稱>/extensions/
   - 全域安裝：SillyTavern/public/scripts/extensions/third-party/
3. 重新啟動 SillyTavern，或重新整理瀏覽器。
4. 點擊魔杖選單中的「墨藍藝廊」，即可開啟介面。

若你的 SillyTavern 支援「從 Git 儲存庫安裝」，需先將此資料夾放入 Git 儲存庫後再貼入網址；本 ZIP 本身不提供自動更新。

## 已接上的功能

- 顯示、搜尋及切換 SillyTavern 中實際存在的聊天室；聊天室刪除後會從列表消失
- 開啟聊天室時只載入供檢視；切換前後會清除生成狀態並維持傳送圖示。未經送出、續寫、重試或摘要等明確操作的生成，會在 SillyTavern 建立中止控制器後再次攔截，群組 Auto Mode 亦會關閉
- 簡約美術風角色總覽：正面先以原始角色圖片高清呈現，點擊圖片立即以絲滑 3D 動畫翻面查看資訊，再點一次卡片背面即可翻回圖片；向右滑上一張、向左滑下一張，切換時具備連續滑出／滑入動畫，亦支援滑鼠拖曳、方向鍵與頁碼圓點
- 修正滑動手勢過早接管單擊事件：點擊角色圖片可穩定翻至資訊面，只有確認水平拖曳後才切換角色卡
- 完整角色卡管理：新增、修改、刪除、匯入 JSON／PNG／YAML／CHARX／BYAF，以及匯出 PNG／JSON
- 玩家設定檔管理：新增、修改、刪除及套用 SillyTavern 原生 Persona；支援玩家名稱、頭像、標題與提供給 AI 的人物描述，並可綁定個別聊天室
- 全部／群組篩選（已移除收藏功能）
- 建立新對話
- 送出訊息、執行 STscript／Slash Command、停止生成
- 檔案附件（沿用 SillyTavern 原生附件流程）
- 訊息輸入快捷工具：`**` 可包住選取文字作為粗體標記，`「」` 可包成中文引號；未選取文字時會插入成對符號並將游標置於中間
- 快速回覆下拉選單：把指定內容插入目前游標位置而不立即傳送；可在管理介面自由新增、修改及刪除，清單保存在 SillyTavern 擴充設定中
- 編輯及刪除訊息
- 重試最後一則角色回覆
- 續寫
- 對話重新命名
- 刪除目前或列表中的任一聊天室；同角色多個聊天室以「角色 ID＋聊天室檔名」分別管理，不會連帶刪除
- 匯出目前或列表中的任一對話為 TXT
- 聊天室開場白切換：讀取角色卡的預設與替代開場白，從「對話選項」選擇後只替換目前聊天室的第一則角色訊息並保存，不影響同角色的其他聊天室
- 專注模式
- 世界書新增、重新命名、匯入、條目修改及刪除
- 介面字體與聊天室訊息字體可分別調整，設定會保留於 SillyTavern
- 所有設定、管理與確認介面會隨網頁及介面縮放同步調整，並依目前可見視窗保持置中；放大後超出高度時可在面板內捲動
- 生成中心直接切換目前 API 可用模型
- 聊天補全預設設定檔：直接連動 SillyTavern 原生 Chat Completion 預設，可切換、複製目前完整參數建立新設定檔、匯入 JSON 及匯出 JSON；保留取樣器、Token、串流、推理與 Prompt Manager 等欄位
- API 實際輸入／回覆 Token、本次與累計用量統計
- 真正送出的使用者訊息次數統計；Swipe、續寫與重新生成不會增加次數
- 世界書、生成中心、使用者設定與更多操作皆在墨藍藝廊內顯示
- 每個聊天室獨立保存關係值與記憶摘要
- 關係值旁提供「?」說明，可查看各數值區間、保存範圍及對回覆的作用方式
- 群組頁面可直接建立群組，從現有角色卡一次指定 1–5 名成員；既有群組也能以同一介面重新選擇成員與回覆方式
- 新建或開啟尚未開始的群組聊天室時會預先建立空白聊天資料，不載入任何成員的角色卡開場白，也不觸發模型生成；玩家送出第一則訊息後才開始群組回覆
- 群組聊天室沿用 SillyTavern 原生群組生成流程：角色會讀取各自角色卡、世界書、後台生成設定與聊天上下文後主動回覆；維持各自口吻、關係與知識邊界，單輪中同一角色最多回覆 2 次
- 記憶自動摘要：自訂提供給 AI 的摘要要求、輸出格式與觸發訊息數；AI 產生後可人工修改並作為後續系統記憶
- 互動狀態欄：可讀取酒館助手「角色腳本」JSON，解析內嵌的 `*CONFIG` 設定並套用於目前聊天室；支援《大晏》互動狀態欄的狀態、食物、物品、關係值、備忘與資源使用介面
- 酒館助手渲染橋接：角色卡已綁定並啟用渲染的《大晏》狀態欄，會自動移入墨藍藝廊輸入框上方；離開介面時安全放回原生聊天區，不需重複匯入
- 狀態欄固定顯示於聊天訊息輸入框正上方，不再放入聊天紀錄頂端；聊天紀錄與狀態欄可各自捲動
- 狀態欄外框、標題列、模式列及底部操作列保持完整可見；內容過長時只捲動中間內容區，避免上下邊框被捲走，並適用於酒館助手橋接狀態欄與手機窄螢幕
- 狀態欄可匯入／替換、啟用／停用、重設、移除，亦可匯出目前聊天的狀態；每個聊天室各自保存，互不共用
- 角色回覆可用 `<!--DAYAN_STATUS {...}-->` 更新欄位、關係值、資源與備忘；未提供的值維持原狀
- 聊天訊息區可獨立上下滑動，不影響輸入框與導覽列
- 桌機與手機版面
- Ctrl/Cmd + Shift + M 快速開關；Esc 關閉

## 資料與相容性

- 對話及角色資料仍由 SillyTavern 儲存。
- 聊天補全預設透過 SillyTavern 原生 Preset Manager 讀寫；匯入同名設定檔前會要求確認，避免無意覆蓋。
- 玩家設定檔直接寫入 SillyTavern 原生 Persona 資料；刪除設定檔不會刪除既有聊天訊息。
- 群組成員與回覆策略直接寫入 SillyTavern 原生群組資料；建立與修改時限制 1–5 名角色。群組聊天室以只有 metadata 的空白聊天檔初始化，避免 SillyTavern 將各成員的第一則訊息加入群組；連續群組回覆模式保持關閉，只有玩家明確送出訊息後才啟動該輪角色回覆。
- 關係值、摘要設定與摘要內容寫入目前聊天室的 chatMetadata.molan_gallery；已儲存摘要會透過 extension prompt 提供給後續 AI 回覆。
- 互動狀態欄設定與目前狀態保存在目前聊天室的 chatMetadata.molan_gallery，各聊天室互不共用；啟用時會將支援的更新格式提供給模型。
- 匯入器只解析 JSON 中的內嵌設定物件，不執行檔案內的 JavaScript、Tavern Helper API、script、iframe、外部資源或行內事件。
- 目前聊天用量寫入 chatMetadata.molan_gallery；全部累計寫入 extensionSettings.molan_gallery。
- Token 只採計 API 供應商回傳的 usage／usageMetadata；供應商未回傳時顯示「未提供」，不以估算值冒充實際用量。
- 關閉擴充後，原生 SillyTavern 介面仍可正常使用。
- 最低支援 SillyTavern 1.18.0；若你的版本較舊，請先更新至目前 release 版。
